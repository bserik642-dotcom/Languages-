Сайтыма Face ID арқылы авторизация жасау функциясын қос. WebAuthn және Passkeys технологияларын қолдан. Пайдаланушы Face ID немесе құрылғының биометриялық аутентификациясы арқылы қауіпсіз кіре алсын. Қазіргі сайттың дизайнын өзгертпе. Функцияны мобильді құрылғыларға бейімде. Backend және authentication жүйесін дұрыс бапта.
